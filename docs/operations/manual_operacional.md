# Manual Operacional do Colaborador

## Passo a Passo
- Passo 1: acessar /colaborador
- Passo 2: abrir tarefas
- Passo 3: selecionar solicitacao
- Passo 4: validar documentos
- Passo 5: enviar para aprovacao

## Rotina Tesouraria
- 09:00: verificar caixa
- 10:00: funding necessario
- 13:00: alocacao em projetos
- 15:00: reconciliacao
- 17:00: relatorio diario

## Rotina Compliance
- checar KYC pendente
- validar AML
- revisar auditoria
- atualizar score de risco
